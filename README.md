## Features

- **Merge PDF** — Combine multiple PDF files into one
- **Split PDF** — Extract pages or split by range
- **Compress PDF** — Reduce file size without quality loss
- **Convert PDF** — PDF to Word, Excel, PPT, Image
- **Edit PDF** — Add text, images, annotations
- **Protect PDF** — Add password encryption
- **All processing happens in your browser** — no file upload, privacy-first

## Tech Stack

- **Framework**: Next.js 15 + React 19 + TypeScript
- **Styling**: Tailwind CSS 4
- **PDF Engine**: pdf-lib + PDF.js (browser-side)
- **Deployment**: Vercel
